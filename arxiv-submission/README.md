## How to Submit to arXiv

### Step 1: Create an arXiv Account
1. Go to [arxiv.org/register](https://arxiv.org/register)
2. Fill in your details
3. Verify your email

### Step 2: Start a New Submission
1. Log in at [arxiv.org](https://arxiv.org)
2. Click "Submit" in the top menu
3. Click "Start New Submission"

### Step 3: Choose Category
- Select: **cs.CL** (Computation and Language)
- Or: **cs.AI** (Artificial Intelligence)
- Secondary: **cs.DL** (Digital Libraries)

### Step 4: Upload Files
1. Upload `main.tex`, `references.bib`, and the `figures/` folder
2. arXiv will compile it automatically
3. Preview the PDF to make sure it looks right

### Step 5: Fill in Metadata
- **Title:** Forbidden Texts and Hidden Networks: A Computational Analysis of Ancient Religious Corpora and the Silent Spirits Legacy Meditation Engine
- **Author:** Aundrae Giles
- **Abstract:** (copy from the abstract in main.tex)
- **Keywords:** computational theology, binaural beats, sacred frequency, consciousness technology, cross-corpus NLP, regenerative principles, chakra frequencies, open-source meditation, prior art
- **Comments:** 20+ pages, 3 figures, 2 tables

### Step 6: Submit
1. Click "Submit"
2. You'll get an email confirmation
3. The paper will appear on arXiv within 24-48 hours

```bash

bibtex main
pdflatex main.tex
pdflatex main.tex
```

### Using Overleaf
1. Create a new project
2. Upload `main.tex`, `references.bib`, and the `figures/` folder
3. Set main document to `main.tex`
4. Compile with PDFLaTeX
