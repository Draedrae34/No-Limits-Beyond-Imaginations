No Limits Favicon

Add this code to the section of your HTML files:

Files needed in images/ folder:

  • favicon.svg - Main vector icon
  • favicon-32x32.png - 32x32 pixel icon
  • favicon-16x16.png - 16x16 pixel icon
  • apple-touch-icon.png - 180x180 for iOS
  • favicon-144x144.png - 144x144 for Windows

Tip: Use an online converter (like favicon.io) to convert the SVG to PNG formats.
