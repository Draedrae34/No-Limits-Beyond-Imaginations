# Google Analytics Setup Guide

## Step 1: Create a Google Cloud Project

1. Go to: https://console.cloud.google.com/
2. Click **"New Project"** 
3. Name it: "No Limits Beyond Limitations"
4. Click **Create**

## Step 2: Enable Google Analytics Data API

1. In your Google Cloud Console, go to **APIs & Services** > **Library**
2. Search for: **"Google Analytics Data API"**
3. Click on it and click **Enable**

## Step 3: Create Service Account Credentials

1. Go to **APIs & Services** > **Credentials**
2. Click **"Create Credentials"** > **"Service Account"**
3. Name: `nlbl-analytics`
4. Description: "Analytics for NLBL Website"
5. Click **Done**
6. Click on the created service account
7. Go to **Keys** tab
8. Click **"Add Key"** > **"Create new key"**
9. Select **JSON** format
10. Click **Create** - this downloads a JSON file

## Step 4: Get Your Property ID

1. Go to: https://analytics.google.com/
2. Click **Admin** (gear icon bottom left)
3. Under "Property" column, click **Property Settings**
4. Copy the **Property ID** (looks like: `123456789`)

## Step 5: Add Service Account to Analytics

1. In Google Analytics Admin, go to **Property Access Management**
2. Click the **+** button
3. Add the service account email from your JSON file:
   ```
   something@project-name.iam.gserviceaccount.com
   ```
4. Set role to: **Viewer**
5. Click **Save**

## Step 6: Add to Vercel

In your Vercel project Settings > Environment Variables, add:

```
GOOGLE_APPLICATION_CREDENTIALS={"type":"service_account","project_id":"your-project-id","private_key":"-----BEGIN PRIVATE KEY-----\nMIIEvQIBADANBgkqhkiG9w0BAQEFAASCBKcwggSjAgEAAoIBA...\n-----END PRIVATE KEY-----\n","client_email":"your-service@project.iam.gserviceaccount.com","client_id":"123456789"}

GA_PROPERTY_ID=123456789
```

**Important:** Replace the `private_key` with the actual private key from your downloaded JSON file (keep the `\n` for line breaks).

---

## Quick Fix: If GA isn't set up, analytics will show placeholder data

Don't worry - the dashboard works fine without Google Analytics! It will just show placeholder traffic data but still display your real Stripe sales data.
