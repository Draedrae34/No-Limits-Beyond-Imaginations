How to run locally (quick)

1) Open a terminal at repo root (D:\Projects\Silent-Spirits-Legacy)
2) Activate the Python venv: .\.venv\Scripts\activate
3) Start the local player server: .\.venv\Scripts\python.exe .\meditation-app\src\web\server.py
4) Open: http://127.0.0.1:8888/src/web/player.html

Reproducible checks

  1. Run: python scripts/audit_manifest.py — ensure manifest matches disk
  2. Run: python scripts/verify_frontend_compat.py — confirm player keys & counts
  3. Start server and verify /api/sessions returns JSON (manifest)
