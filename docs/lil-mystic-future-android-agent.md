# Lil Mystic Future Android Agent Notes

## Purpose

Explore a future version of Lil Mystic that can operate apps autonomously for legal automation and productivity tasks.

## Possible Paths

### Android Accessibility Service

- Build an Android app with Accessibility permissions.
- Add screen reading.
- Add automated tapping and swiping.
- Add workflow automation.
- Useful for productivity flows, reminders, repetitive phone tasks, and owner-approved app automation.
- Avoid cheating, bypassing security, or violating app and game rules.

### Cloud Android Emulator + AI Vision

- Run a cloud Android device.
- Let AI vision inspect the screen.
- Use a tap-control API for actions.
- Run a loop system for repeatable tasks.
- Keep the phone free from battery drain and interruptions.
- Avoid anti-ban or evasion work; focus on allowed automation and business workflows.

### Game-Specific Helpers

- Use only game-supported auto-play, auto-farm, auto-battle, reminders, scheduling, and progress tracking.
- Do not build cheating tools or bypass game protections.

### Business Automation

- Run shop workflows.
- Manage catalog updates.
- Generate designs.
- Handle marketing ideas and content.
- Optimize repeated workshop tasks.

## Roadmap

### Phase 1: Android Agent Mode

- Android app.
- Accessibility Service.
- Screen capture.
- Tap automation.
- AI vision.
- Task scripts.

### Phase 2: Cloud Device Automation

- Cloud Android instance.
- AI-controlled device loop.
- Remote monitoring from phone.
- No dependency on the personal phone being awake.

### Phase 3: Agent Brain

- Goal-based task planning.
- Vision and action loops.
- Progress tracking.
- Multi-app workflows.

## Boundary

Lil Mystic should help with legal automation, owner-approved productivity, business workflows, and accessibility-style assistance. Lil Mystic should not help bypass security, cheat in games, evade detection, defeat account protections, or break app rules.
