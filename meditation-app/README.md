# Silent Spirits Legacy — Meditation App

Deployed with Railway. This backend serves the full meditation app with all 63 audio tracks.

## Local Development
```bash
python src/web/server.py
```

## Deploy to Railway
1. Push this folder to GitHub
2. Go to railway.app → New Project → Deploy from GitHub
3. Select this repo
4. Railway auto-detects Python and deploys

The app will be live at a Railway.app URL with HTTPS.
